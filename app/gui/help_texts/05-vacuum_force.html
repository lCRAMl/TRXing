Haltekraft

<>

Die mechanische Grenze ist keine Formalie. Bei SPB2 30 stehen 14,4 N Saugkraft einer Querkraft von nur 12,8 N gegenueber – beim seitlichen Griff begrenzt also schon bei −0,6 bar der Sauger, nicht das Vakuum. Die Abreisskraft dagegen wird mit Vakuum allein bei den meisten Groessen nie erreicht.

Erforderliche Kraft

<>

Die Beschleunigung a steht standardmaessig auf null; das Ergebnis ist dann die rein statische Rechnung. Wer die Beschleunigung seines Portals oder Roboters eintraegt, bekommt den realistischen Wert – beim Palettieren ist der Unterschied betraechtlich.

Beim seitlichen Griff haengt die Last an der Reibung zwischen Sauger und Karton; die Normalkraft muss um den Kehrwert des Reibbeiwerts groesser sein. Der Reibbeiwert ist eine Benutzerangabe und steht in keinem Datenblatt.

Jedes Paket einzeln

Die Bilanz oben summiert: alle Haltekraefte gegen alle Massen. Darin steckt eine Annahme, die nicht stimmt – dass die Platte Kraft von einem Paket zum naechsten weiterreichen koennte. Sie kann es nicht. Jedes Paket haengt an genau den Saugern ueber ihm.

Der Unterschied ist nicht klein. Mit den Vorgabewerten und acht Paketen (Platte 800 x 600 mm, Paket 400 x 300 mm, SPB2 30) liegen vier Pakete bei x = −400 und x = 800 und damit vollstaendig ausserhalb der Platte:

< Sicher je Paket Paket 1 0 Sauger 0 N gegen 98 N -> Nicht ausreichend Paket 2 88 Sauger 1267 N gegen 98 N -> Sicher ... >>

Deshalb rechnet die Anwendung dieselbe Kraftbilanz ein zweites Mal – je Paket, mit den Saugern darueber und der Masse eines Pakets. Das Vakuum ist dabei fuer alle gleich: es gibt nur eine Platte und einen Erzeuger, ein offener Sauger ueber Paket 1 senkt also auch die Haltekraft ueber Paket 8.

Das Gesamturteil ist danach das schlechteste dieser Urteile, nie ein Mittelwert: ein Paket, das faellt, faellt. In der Zeichnung traegt der Rahmen jedes Pakets die Farbe seines eigenen Urteils – gruen heisst "die Sauger ueber diesem Paket heben es", nicht "die Platte schafft die Summe". Die Zeile Pakete, davon tragend nennt die Zahl, und das Protokoll nennt die Pakete beim Namen.
